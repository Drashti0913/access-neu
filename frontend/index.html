How to use AccessNEU

Access reports

  1. Open Access reports.
  2. Use the filters to pick a building, category or status, then select Apply filters.
  3. To report a barrier, fill in the Report a barrier form and select Submit report.
  4. On any report, select Mark resolved once it is fixed, Edit to correct details, or Delete to remove a duplicate.

Quiet spaces

  1. Open Quiet spaces.
  2. Filter by building, noise level, lighting or a feature such as step-free access.
  3. To add a space, fill in the Add a quiet space form.
  4. Select Edit to update hours or features, or Delete if a space has closed.

No account is needed. Please keep reports factual and do not include personal information about other people.
